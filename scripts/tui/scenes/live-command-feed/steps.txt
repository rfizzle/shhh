# A long command in flight, on the two surfaces it occupies: the feed's row —
# the command, its outcome, its own clock and the last line it printed — and
# the frame's top rail, which states the phase and the turn's clock and
# repeats none of it. Read the cells against the live-command goldens: the
# command is bounded by the activity row's grammar rather than cut on the
# rail, the rail carries no copy of it, and of the two clocks on screen only
# the rail's says `turn`. The command is the turn's first call, so no step's
# card holds it yet and the row under the transcript is where it runs; once
# it lands it is a card (docs/interface/surfaces.md#the-step), its first line
# out under the header.
#
# The frame's status is what animates for the turn: the
# row's glyph is the still `▸`, and no total line counts the turn under the
# transcript — the turn's last line appears only when it ends
# (docs/interface/surfaces.md#the-turns-close). The second turn runs its
# command inside a step that is already a card: the card keeps `$` in its
# glyph slot, its clock counts the command still running, and the command's
# last line out stands under its body, the last thing above the frame. Grep
# the captures for a braille frame: only the frame's top rail draws one.

# second line's file instead.
