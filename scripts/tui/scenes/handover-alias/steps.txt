# program test: TestProgram_TheHandoversCoverAnswersFromAHalfTypedLine,
#   TestProgram_ACardsKeyIsInertUntilTheHandover
#
# A decision that lands mid-sentence names both chords that hand it the
# keyboard, and the cover works: macOS takes ctrl+space for its input-source
# switcher before the terminal sees it, so the card says ctrl+y beside it
# (docs/interface/principles.md#a-key-is-inert-until-its-surface-holds-the-keyboard).
# tmux sends ctrl+y here; what this cannot show is whether a Mac delivered a
# physical ctrl+space, which is the desktop's decision and not the program's.
#
# Driven at 60 columns, the narrowest the card is drawn at, where the two
# chords and the imperative still fit on the one row the card keeps for them.
snap 01-start "Some things worth doing first"
keys "write down what we settled on" Enter
# At 60 columns the held card's esc ends the offers row, cut to the bare key
# rather than given a row of its own
# (docs/interface/surfaces.md#the-approval-card).
narrow 61 snap 02-card "notes.md" "[n] deny · [?] keys · [esc]"
wide 61 snap 02-card "notes.md"
# A card that has just landed holds its keys for a beat, so the typing waits
# for the grace window rather than racing it. The sentence carries a bare y:
# beside a live draft it is a letter, not the card's allow.
sleep 1
keys "and say y"
# Every framed width carries a foot row of keys (surfaces.md#the-input-frame),
# so below the wide layout the handover is named on the frame's own foot
# rail, leading the ladder, rather than on a notice rail above the box. The
# compared row is the foot rail's, where the card's own offer stands behind
# its border above.
snap 03-draft-keeps-the-keyboard "and say y" "[ctrl+space/ctrl+y] answer it" "╰─ [ctrl+space/ctrl+y] answer it"
keys C-y
snap 04-card-holds-the-keyboard "[y] apply" "notes.md"
keys y
# Answered, the sentence typed while the card waited goes with the answer as
# its note — the transcript carries it as the reader's own steer — and the
# keyboard comes back to an empty draft
# (docs/capabilities/approvals-and-safety.md#a-no-can-say-why-and-a-yes-can-say-what-next).
snap 05-answered "The note is written" "and say y"
# The draft is empty, so the first press arms the quit rather than clearing.
keys C-c
snap 06-quit-armed "again quits"
keys C-c
# The quit offers a handoff over uncommitted work; n declines.
snap 07a-handoff-offer "Write a handoff first?" "Changes are uncommitted.  [y/N]"
keys n
snap 07-exit "that is everything the screen was holding"
