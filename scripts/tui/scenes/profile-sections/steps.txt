# program test: TestProgram_TheDraftIsRevisedOneSectionAtATime
#
# The profile drafter's draft step at 80 columns
# (docs/interface/surfaces.md#the-profile-drafter).
#
# What the capture is for: the draft arrives as its sections, one block each,
# with the pointer on Purpose and Report marked empty; a note about Method is
# sent and only Method comes back rewritten, marked refined, though the answer
# rewrote every section; Restrictions goes through the editor and comes back
# marked as the person's own; esc takes that back; and tab hands the keyboard
# to the card, whose pane folds rather than giving ground; then one note for
# the whole draft rewrites every section but the one the person wrote, and
# esc on the row it leaves takes it back; last, the Commands block is revised
# on a note, cleared and given back.
snap 01-start "Some things worth doing first"
keys "/agents new a test writer" Enter
snap 02-sections "[enter] refine it with a note" "❯ Purpose" "Report ⚠ empty · the drafter left it"
keys Down Down Down Enter
snap 03-note "what to change in Method"
keys "run go vet as well"
keys Enter
snap 04-refined "Method · refined once" "Never change an expected value" "Add table-driven tests"
# The editor opens on the section under the pointer, so the pointer is seen
# on Restrictions before the key that opens it: a press counted against rows
# still being drawn would open another section.
keys Up
snap 04b-on-restrictions "❯ Restrictions"
keys e
snap 05-edited "Restrictions · edited by you" "NEVER change an expected value"
keys Escape
snap 06-taken-back "[esc] discard the draft" "Never change an expected value"
keys Tab
snap 07-card "[enter] confirm · [tab] the sections" "Keep test-writer?"
# The Tools block opens its selector where the card stood: the tiers the
# draft granted ticked, the tools this session registered under them, and
# the note saying what write or execute make of the agent. Execute and write
# are unticked — the note says it changes nothing — write is ticked again and
# the note says it is a writer, and enter takes the pick into the block.
keys Tab Down Down Down Enter
snap 08-selector "What may test-writer do?" "test-writer is a writer" "navigation · notebook · skills"
keys Down Down Space Up Space
snap 09-reads "test-writer changes nothing"
keys Space
snap 10-writer "test-writer is a writer"
keys Enter
snap 11-taken "read + write" "[enter] open the selector"
# One note for the whole draft: Restrictions is written in the editor first,
# so the note under the section list names it as kept; the answer rewrites
# every section and the fields, and only the other sections are taken, each
# marked, with the note's own row under them holding the pointer. esc there
# takes the note back from every section it changed.
keys Up Up Up
snap 11b-on-restrictions "❯ Restrictions"
keys e
snap 12-mine "Restrictions · edited by you"
keys R
snap 13-whole-note "a note on the whole draft" "you edited, is kept" "[R] again to include the sections you edited"
keys "terser throughout"
keys Enter
snap 14-whole "Whole draft · redrafted on your note" "Restrictions kept as you" "[esc] take it back from every section it changed"
keys Escape
snap 15-whole-back "❯ Model" "[esc] discard the draft"
# The Commands block takes the prose sections' keys: it states nothing yet,
# a note about it comes back with its two fields — and every section
# rewritten besides, of which nothing is taken — x clears it back to the
# session's own lists, and esc takes the clear back.
keys Up
snap 16-commands "❯ Commands" "none stated · the session's own command lists apply" "[e] edit it yourself"
keys Enter
snap 17-commands-note "what to change in Commands"
keys "it must never push or install"
keys Enter
snap 18-commands-refined "Commands · refined once" "for: running the package's tests and go vet" "never: git push, go install"
keys d
snap 19-commands-cleared "Commands · you cleared it" "none stated"
keys Escape
snap 20-commands-back "never: git push, go install" "[esc] take back its last revision"
