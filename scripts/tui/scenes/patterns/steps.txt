#
# What repeats, proposed
# (docs/capabilities/sessions-and-memory.md#memory-is-what-shhh-knows-about-your-project).
# The setup migrates the run's store with one run of the binary, trusts the
# checkout, and seeds three sessions of it through seed.py beside this file:
# each reads main.go, is asked about `go test ./...` and allows it, runs go
# vet, go build and go test in that order, and has its default suite fail
# before it passes. The goldens are patterns-start and patterns.
#
# The start screen's read-only slot offers `look at what repeats — 3
# patterns` (the file, the command, the suite: the start count reads the
# tables alone). The row opens /patterns, which lists four proposals — the
# sequence is read from the conversations once the list opens. The second row
# is the allowlist line, and its card shows the line the checkout's settings
# would gain with `[y] write it · [n] not now · [N] never`, read against the
# patterns golden's card. [N] writes the no and nothing else.
#
# The identity is repository-local because the pane runs under a home of its
# own, so there is no global one for the commit to find.
setup git config user.email tui@shhh
setup git config user.name tui
setup printf 'package main\n' > main.go && git add main.go && git commit -q -m main
setup HOME=$home XDG_DATA_HOME=$home/data XDG_CONFIG_HOME=$home/config "$SHHH_BIN" trust >/dev/null
setup python3 "$scene/seed.py" "$home/data/shhh/shhh.db" "$PWD"
snap 01-start "look at what repeats — 3 patterns" "Some things worth doing first" "reads only, then asks"
keys Down
snap 02-chosen "❯ ⚙ look at what repeats"
keys Enter
snap 03-list "/patterns · 4 proposals" "allowlist" "go test" "go vet → go build → go test" "main.go"
keys Down Enter
snap 04-card "[N] never" "Approve allowlist line" "command_allowlist = [\"go test\"]" "[y] write it · [n] not now"
keys N
snap 05-never "will not be proposed again"
