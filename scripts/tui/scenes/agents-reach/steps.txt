# The rail's map with a fan-out under it, at 130 columns — the rung where the
# content splits, so the AGENTS block is on screen beside the transcript
# (docs/interface/surfaces.md#the-inspector-rail).
#
# What the capture is for: the map is somewhere to go from. The trailer under
# the block names the manager, the chord and the pointer; a child waiting on
# an answer is drawn directly under the orchestrator whatever order it was
# spawned in; a child a child spawned is drawn a column in behind the corner;
# and a child that failed says so on its own line. Both doors the trailer
# names are driven here — the chord that walks the map, and the key that opens
# the manager — so the row is proof of the keys rather than a sentence about
# them.
setup printf 'package agent\n\nfunc loop() {\n    for round := 0; round < limit; round++ {\n        step()\n    }\n}\n' > loop.go
snap 01-start "Some things worth doing first"
keys "survey the round accounting" Enter
# Spawning is gated, so a card stands between the sentence and each child.
snap 02-spawn-card "writer agent"
keys y
sleep 1
keys y
sleep 1
keys y
sleep 3
# One of the writers hands a part of its own task down, and the card for that
# is the person's the way the session's three were: starting an agent is a
# decision wherever in the tree it is taken
# (docs/capabilities/subagents.md#a-child-may-delegate-to-a-configured-depth).
# Every other agent is still reading here, so this card is the one at the
# front of the queue rather than one of four racing for it.
snap 03-delegates "spawn_agent"
keys y
sleep 3
# And the level the session did not ask for, on the map: the grandchild under
# the agent that spawned it, a column in behind the corner.
snap 04-nested "reader-3a"
# Everything then asks to run a command at once: the session's own request is
# a card of its own, and the children's are routed here to be answered. The
# queue counter is what says how many are standing behind this one.
snap 05-routed "DECISION"
# The session's own is declined, which leaves the routed ones — and a routed
# request nobody has answered is what makes a child blocked.
keys n
sleep 3
snap 06-blocked "waiting approval"
# The manager is the door the trailer names for acting rather than reading:
# one child is killed here, which is the failure the map then carries.

# Attaching to a session that is not the one asking is what puts the rail back
# with the map whole: the block floated to the top, the failure under it, the
# grandchild indented under its own parent, and the trailer naming the way
# out. The session attached to here is the grandchild itself, three rows down
# the manager's list, so the frame's breadcrumb is the lineage as well.
keys j

# The chord itself, twice: it walks spawn order rather than the order the map
# is drawn in, and from the grandchild — the last thing spawned, and the

# promised the key would move.
