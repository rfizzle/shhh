# One reply queue per agent, opened by a [name] header: the session, each of
# the three writers it fans out, and the child one of those writers delegates
# to. Each queue is that agent's own rounds in its own order, so what reaches
# the screen is the scene's sequence and not the race between four agents all
# asking the same endpoint at once.
#
# The one thing the queues have to arrange between them is which card is at
# the front when a snap is taken, and reads are far too fast to arrange it
# with. So the three agents that must not interrupt hold their connection open
# instead (`wait:`), and writer-3's delegation is its very first round: it is
# the only gated call in flight for the next several seconds, so it is the
# card the scene answers.
#
# The sentence and the three spawns are one reply, so the transcript titles
# the step with the sentence rather than closing a turn before the calls were
# asked for.
