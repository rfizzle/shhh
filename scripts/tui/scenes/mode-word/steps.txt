# The permission mode is the one field on the frame that is read before every
# keystroke, so it is written in one closed vocabulary: the class the mark
# already means, and the mode's own name after it only where the class covers
# more than one mode (docs/interface/surfaces.md#the-input-frame).
#
# What the capture is for: the cycle key walked all the way round, one snap
# per mode, so the marks and the words are read against each other rather than
# one at a time — ⏵⏵ in add where work goes through, ⏸ in accent where
# something is gated, and never two words for one state. The child's frame at
# the end says the same thing about the agent the keyboard moved into.
#
# The turn comes first so the segment is read where it is really read: in
# front of the counters, on a frame that has something to report.
