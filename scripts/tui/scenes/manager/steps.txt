# The process manager (docs/interface/surfaces.md#the-process-manager): what
# the session left running, each thing a key from its output and a key from
# its stop. The session starts a process that prints a line a second, then
# fetches a page the scripted endpoint takes a minute to serve. The scene
# opens /ps while the fetch waits and stops the fetch alone; the turn goes on
# to its last reply, which is held for twenty seconds, and while it is still
# running the scene stops the process as well.
#
# The slow call is a fetch rather than a command on purpose: a command needs
# a containment mechanism on the host, and a fetch needs none. A started
# process needs none either: the supervisor starts it.
#
# What the capture is for: at 04, at 130 columns, the rail draws PROCESSES
# with the ticker running and CALLS with the fetch in flight, beside where
# AGENTS would stand; at 05 /ps lists both, the ticker under processes and
# the fetch under tools, each with its age and where it runs; at 06 enter has
# opened the ticker onto its output, the read the process tool returns, with
# its `tick` lines; at 07, back on the list and down a row, d asks about the
# fetch with the agent manager's two answers; at 08 y has stopped the fetch
# alone — the tools section reads `nothing running` and the ticker still
# runs; at 09 d asks about the ticker, and at 10 y has stopped it and its row
# reads cancelled; at 11, out of the manager with the turn still running, the
# fetch's row in the transcript reads cancelled and the process's stop is said
# under it; at 12 the turn finishes on its last reply.
#
# Each esc is followed by a pause: an esc and the next key inside the
# terminal's escape timeout read as one alt chord.
snap 01-start "Some things worth doing first"
keys "start the ticker and read the release notes" Enter
# A start is a command to approve. The card lands a moment after the enter,
# inside its grace window, so the answer waits the window out.

# The fetch is a card of its own; its domain row is the endpoint.
snap 03-fetch-card "127.0.0.1"
