# The transcript reports rather than narrating
# (docs/interface/surfaces.md#the-activity-row). What the reader sent is a ❯
# row with a rule under it, what came back is prose with no label at all, and
# the card the second turn reaches opens with the act — the glyph and the
# command — instead of a sentence about who wants it.
#
# Nothing here writes to the workspace it is driven in: the one command that
# reaches a card is denied.
#
# Spaces rather than tabs in the fixtures: a tab is re-expanded by the
# terminal against the pane's own columns, not the row's, and the capture
# would read as a column that drifted.
setup printf 'package agent\n\nfunc loop() {\n    for round := 0; round < limit; round++ {\n        step()\n    }\n}\n' > loop.go
snap 01-start "Some things worth doing first"
keys "make the round limit recoverable" Enter
# The reply is prose and nothing else, under the ❯ row and its rule.
snap 02-reply "Threading a sentinel through it"
keys "now run the agent tests" Enter
# A card that lands on an empty draft takes the keyboard with a grace window
# open, so the answer waits for the window to close rather than racing it.
snap 03-card "go test ./internal/agent/..."
sleep 1
keys n
snap 04-answered "That is the shape of it"
keys C-c
snap 05-quit-armed "press again to quit"
keys C-c
snap 06-exit "that is everything the screen was holding"
