# One turn watches its tests fail, fixes the code, and runs the repository's
# own suite over what came out of it. Read the cells for one unambiguous final
# verdict (docs/interface/surfaces.md#the-turns-close): at 03 the failing
# command is standing bad news on the rail, at 04 the same card is still in
# the feed with the outcome it had while the rail no longer carries
# an alert for it and the close row reads the suite's pass. Nowhere do the two
# say different things about one turn. Inspect the picture for the alert
# treatment: the failed card keeps its del glyph and a del mutation rail, the rail's
# alert is del while it stands, and the close row's verdict is add.
#
# The suite's vet check fails on every other run (a marker file the gitignore
# keeps out of the tree's fingerprint), so the gate runs it once more and the
# close row reads the pass with `1 flaked` beside the count of checks, as the
# on-close-gate golden's flaked state does. A second turn runs the suite
# again: vet flakes a second time, and the close row's note column says it
# has flaked once before, the ledger's count, as the golden's flaked state
# says three times. `/gate flakes` then lists the checkout's ledger, read
# against the flakes-screen golden: vet in default, 2 times.
setup mkdir -p .shhh checks
setup printf 'test:\n\t@echo "--- FAIL: TestLoopRounds"; echo "    loop_test.go:214: want 3 rounds, got 4"; exit 1\n' > Makefile
setup printf '#!/bin/sh\necho "ok  github.com/tui/agent  0.4s"\n' > checks/unit.sh; chmod +x checks/unit.sh
setup printf '.vet-ran\n' > .gitignore
setup printf '#!/bin/sh\nif [ -e .vet-ran ]; then rm .vet-ran; exit 0; fi\ntouch .vet-ran\necho "vet: lost a race with its sibling"\nexit 1\n' > checks/vet.sh; chmod +x checks/vet.sh
setup printf '{"suites":{"default":{"allow_write":true,"checks":[{"name":"test","exe":"./checks/unit.sh"},{"name":"vet","exe":"./checks/vet.sh"}]}}}\n' > .shhh/quality.json
snap 01-start "Some things worth doing first"
keys "stop the loop double-counting rounds" Enter
snap 02-card "make test"
keys y
snap 03-alert-standing "▎✗ ran make test" "exit 2"
snap 04-resolved "quality gate default passing" "exit 2 · approved by you" "· 2 of 2 checks · 1 flaked ·"
keys "run the suite once more" Enter
snap 05-flaked-again "flaked 1 time before · /gate flakes" "· 2 of 2 checks · 1 flaked ·"
keys "/gate flakes" Enter
snap 06-flakes "flaked 2 times in this checkout" "/gate flakes · 1 check · 2 flakes" "default · 2 times" "./checks/vet.sh" "the failing run exited 1"
keys q
snap 07-back "vet flaked a second time"
keys C-c
snap 08-quit-armed "again quits"
keys C-c
snap 09-exit "that is everything the screen was holding"
