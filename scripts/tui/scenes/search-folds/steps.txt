# The transcript search reaches inside the cards
# (docs/interface/surfaces.md#reading-mode). The turn leaves one step, drawn
# as a card that states its four reads on its header and stands in for their
# rows. The path the reader then searches for is on one of those rows and on
# nothing the pane is drawing, so every count on the screen is a count of
# what the entries hold rather than of what happened to be open.
#
# Spaces rather than tabs in the fixtures: a tab is re-expanded by the
# terminal against the pane's own columns, not the row's, and the capture
# would read as a column that drifted.
setup printf 'package agent\n\nfunc loop() {\n    for round := 0; round < limit; round++ {\n        step()\n    }\n}\n' > loop.go
setup printf 'package agent\n\nfunc round() int {\n    return limit\n}\n' > round.go
setup printf 'package agent\n\nvar ErrRoundLimit = errors.New("round limit")\n' > errors.go
setup printf 'package agent\n\nconst limit = 25\n' > limit.go

keys "how is the round limit counted" Enter
snap 02-turn "The limit is a checkpoint, not a wall"
# Reading mode, and the step a card: four reads happened and the screen is
# holding one header about them.
keys C-o
snap 03-reading "Locate the round accounting"
# The cursor opens on the turn's close; up twice is the card, past the answer
# standing between them.
keys k
keys k
snap 03-on-the-card "❯ ⚙ read 4 files"
# The query. Nothing on the pane is drawing errors.go, so a search over the
# rendered lines would answer none — the rail's count and the card's are
# both counts of what the entries hold.
keys "/"
keys "errors.go"
snap 04-counted "match inside" "1 match inside"
# Enter closes the query row; the next enter is the card's, and it opens the
# card onto its calls: the path is on the screen, bold, on the row the cursor
# has gone to.

keys Enter
snap 05-reached "errors.go · 1/1" "❯  ⚙ read    errors.go"
# The query row again — [/] reopens it over the query that is still standing —
# and esc on the row clears it. The card the search opened goes back with it,
# so the card stands in for its rows again, and the mode the reader was in is still
# there with its own label back on the rail.
