# An applied edit and a refused call (docs/interface/surfaces.md#the-activity-row).
# The edit is the archetypal mutation and used to be the one row in the
# transcript with no rail on it: the picture is looked at for the rail on its
# card and, with the card opened, the rail in the gutter of its row, the ✎
# in the same column as the read's ⚙ above it, and the path followed by the
# first line the edit changed rather than a verb column.
#
# The refusal below it is the other half. A call the queue would not put to
# anybody is a card of its own — ⊘, `skipped` in the outcome with why beside
# it, why it was skipped as its footer, and the rail still in the gutter
# because a refusal is a decision — rather than a sentence hanging off the
# left edge of a pane made of columns.
#
# Spaces rather than tabs in the fixture: a tab is re-expanded by the
# terminal against the pane's own columns, not the row's, and the capture
# would read as a column that drifted.
setup printf 'package agent\n\nconst limit = 25\n\nfunc round() int {\n    return limit\n}\n' > loop.go
setup printf 'The cap is read from one place.\n' > notes.md
snap 01-start "Some things worth doing first"
keys "raise the round cap" Enter
# The edit is gated, so the card is what the turn stops on. Each answer waits
# out the card's grace window and then hands the keyboard over before
# pressing: a letter that arrives while the draft still holds the keyboard
# goes into the draft, and a card beside a draft with anything in it never
# takes the keyboard at all.
snap 02-card "const limit = 50"
sleep 1
keys C-Space
sleep 0.3
keys y
# The command that moves the file under the model is the second decision, and
# it is answered the same way — the handover only ever gives the keyboard to
# the card, so asking twice costs nothing.
snap 03-command-card "const limit = 12"
sleep 1
keys C-Space
sleep 0.3
keys y
# The refusal under the calls that ran: the write never reaches a decision,
# so the turn runs to its last sentence on its own, and it is a card of its
# own beside the card of the calls.
snap 04-cards "The cap is where the file says it is" "▎✎ read loop.go · wrote loop.go" "skipped · changed since it was read"
# The row the scene is for is inside the first card, so the card is opened.
# The cursor opens on the turn's close, and the card is three stops above it.
keys C-o
snap 05-reading "[↑↓/jk] move"
keys k
keys k
keys k
snap 06-on-the-card "[enter] open it"
keys Enter
snap 07-rows "+1 −1 · 1 hunk · approved by you" "▎✎ loop.go · - const limit = 25"
keys Escape
sleep 0.3
keys C-c
snap 08-quit-armed "again quits"
keys C-c
# The quit offers a handoff over uncommitted work; n declines.
snap 09a-handoff-offer "Write a handoff first?" "Changes are uncommitted.  [y/N]"
keys n
snap 09-exit "that is everything the screen was holding"
