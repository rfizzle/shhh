# One queue per agent: the session, and each of the seven writers it fans
# out. With the default three slots a level, three writers start and four
# stand queued behind them, and nothing in the scene frees a slot: writer-1
# asks to write a file the reader never approves, so it is the child waiting
# on you, and writer-2 and writer-3 go on reading, slowly, for as long as the
# scene runs. The last reply of a queue repeats once it runs out, so a reply
# that ends on a call held behind a wait is an agent still working at every
# snap after it starts.
#
# The four queued writers have queues of their own in the same shape, so that
# a slot freed on a loaded host starts a writer that goes on working rather
# than one answered with a line that ends its turn.
#
# The sentence and the seven spawns are one reply, so the transcript titles
# the step with the sentence rather than closing a turn before the calls were
# asked for.
