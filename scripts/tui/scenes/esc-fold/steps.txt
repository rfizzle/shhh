# Esc on an empty draft folds every row the reader opened
# (docs/interface/surfaces.md#the-input-frame). The pane is read through the
# pointer — the draft keeps the keyboard and every letter it has — and then
# put back with the key that already means "leave what is open".
#
# Spaces rather than tabs in the fixtures: a tab is re-expanded by the
# terminal against the pane's own columns, not the row's, and the capture
# would read as a column that drifted.
setup printf 'package agent\n\nfunc loop() {\n    for round := 0; round < limit; round++ {\n        step()\n    }\n}\n' > loop.go
setup printf 'package agent\n\nconst limit = 25\n\nfunc round() int {\n    return limit\n}\n' > round.go
snap 01-start "Some things worth doing first"
keys "how is the round limit counted" Enter
snap 02-turn "The limit is a checkpoint, not a wall"
# Two rows opened through the pointer, one at a time — which is a press per
# row, and what the one press below undoes: shift+↑ lights the pointer and
# walks it up the pane, shift+→ opens the row it is on. The draft keeps the
# keyboard throughout.
keys S-Up
keys S-Up S-Up S-Up
keys S-Right
keys S-Up
keys S-Right
snap 03-open "const limit = 25"
# The pointer is the thing most recently put on screen, so it is what the
# first esc leaves; the second is the one that folds.
keys Escape
sleep 0.5
keys Escape
snap 04-folded "folded 2 rows"
# And the chain goes on meaning what it always meant: the two presses of the
# rewind gesture, unchanged, after the one that folded. The sleeps are the
# terminal's, not the product's — two escapes written into the pty together
# arrive as one sequence — and they stay well inside the gesture's window.
keys Escape
sleep 0.2
keys Escape
snap 05-rewind "Rewind to before"
# Esc leaves the picker having changed nothing, and the session ends the way
# every scene ends: the cancel chord, twice.
keys Escape
sleep 0.3
keys C-c
snap 06-quit-armed "again quits"
keys C-c
snap 07-exit "that is everything the screen was holding"
